# DESIGN_SPEC — Professional Enterprise Light

สเปกการออกแบบสำหรับปรับ UI ของระบบติดตามงานทำความสะอาด (มือถือแม่บ้าน/หัวหน้า + คอมพิวเตอร์แอดมิน)
ใช้คู่กับ `design-tokens.css` (Tailwind v4 `@theme`) และไฟล์แบบใน `mockups/`

> ข้อมูลในแบบทั้งหมดเป็นชื่อและตัวเลขสมมติ **ห้ามนำไปใส่ในโค้ดที่ใช้งานจริง** ใช้ข้อมูลจริงจาก API เดิมเท่านั้น

---

## 0. ขอบเขตและสิ่งที่ห้ามเปลี่ยน

- ปรับเฉพาะ Presentation Layer (layout, spacing, สี, ตัวอักษร, component หน้าตา)
- **ห้ามเปลี่ยน**: API endpoint/payload/response, business logic, validation, auth/role/permission, routes/query params/deep links, ลำดับการทำงานของ form/CRUD/search/filter/sort/pagination/upload
- ต้องคงสถานะ Loading / Error / Empty / Success / Disabled ของทุกหน้า
- **ป้าย QR ที่พิมพ์ (หน้า 16) ห้ามเปลี่ยนหน้าตา** เพราะติดผนังแล้ว ปรับได้เฉพาะหน้าจอรอบ ๆ พรีวิว
- ห้ามติดตั้ง dependency ใหม่ ใช้ Styling ที่มีอยู่ (Tailwind) + ไอคอนชุดที่โปรเจกต์ใช้อยู่ (แบบใช้ไอคอนแนว lucide)

## 1. หลักการ

1. พื้นเทาอ่อน เนื้อหาบนพื้นขาว ตัวหนังสือเข้ม ลดเงา/ไล่สี/ของตกแต่ง
2. **สีน้ำเงิน (accent) = กดได้เท่านั้น** · แดง/ส้ม/เขียว/ฟ้าเขียว/เทา/ม่วง = สถานะเท่านั้น
3. สถานะต้องมี **คำ + ไอคอน** เสมอ ห้ามใช้สีอย่างเดียว
4. ปุ่มหลัก (สีน้ำเงินทึบ) ได้ **1 ปุ่มต่อหน้าจอ**
5. ไอคอนอยู่คู่กับคำเสมอ ไม่มีปุ่มไอคอนอย่างเดียว ไม่ใช้ emoji
6. ระยะห่างทุกค่ามาจากสเกล 4 px
7. ตัวอักษรเล็กสุด 13 px · contrast ตัวหนังสือ ≥ 4.5:1 · ขอบปุ่ม/ไอคอน ≥ 3:1 · มี focus ring ทุกตัวที่กดได้
8. line-height 1.5 (สระไทยบนล่างไม่ชน) หัวข้อ 1.3

## 4. Layout

### คอมพิวเตอร์ (≥1024)
- Sidebar ซ้ายกว้าง 240 px พื้นขาว ขอบขวา `border` · ชื่อระบบ + "แอดมิน" ด้านบน
- เมนูแบ่ง 2 กลุ่ม:
  - **ติดตามงาน**: สถานะจุด · การเข้างาน · รายการที่ขึ้นเตือน (badge จำนวน สีแดง) · สรุปการตรวจ · ส่งออก Excel
  - **ตั้งค่า**: พื้นที่และป้าย · ตึก · พิมพ์ป้าย · บัญชีผู้ใช้ · ประวัติการแก้ไข
  - รายการสูง 40 px, ตัวที่เลือก = พื้น accent-subtle ตัวหนังสือ accent + `aria-current="page"`
  - ล่างสุด: ชื่อผู้ใช้ + ลิงก์ออกจากระบบ
- เนื้อหา: padding 24 px, กว้างสุด 1216 px จัดกลาง
- Page header: ชื่อเพจ 24/700 + คำอธิบาย 14 text-2 ทางซ้าย · ปุ่มการกระทำทางขวา
- ระยะระหว่างส่วน 24 px

### แท็บเล็ต / จอแคบ
- Sidebar ย้ายไปอยู่บน (stack) · ตารางกว้างอยู่ในกล่อง `overflow-x: auto` ห้ามให้ทั้งหน้าเลื่อนแนวนอน · toolbar/ตัวกรอง wrap

### มือถือ
- คอลัมน์เดียว กว้างสุด 480 px ขอบ 16 px
- โครง: Header ขาว (ชื่อคน/พื้นที่/กะ) → เนื้อหาเลื่อนได้ → แถบล่างขาวมีปุ่มหลัก 56 px เต็มความกว้าง
- เคารพ safe area: `padding-top: max(12px, env(safe-area-inset-top))`, `padding-bottom: max(12px, env(safe-area-inset-bottom))`
- ปุ่มสูงอย่างน้อย 48 px · ห้ามมีอะไรที่ต้อง hover · ใช้ได้ที่ 375 px ไม่เลื่อนแนวนอน

## 5. Components

### Button
| ชนิด | สไตล์ | สูง (คอม/มือถือ) |
|---|---|---|
| Primary | พื้น accent ตัวขาว | 36 / 56 |
| Secondary | พื้นขาว ขอบ border-control ตัว text | 36 / 48 |
| Text | ไม่มีพื้น ตัว accent | 32–36 / 44 |
| Danger | พื้นขาว ขอบ+ตัว #B42318 → ยืนยันด้วย Modal ปุ่มแดงทึบ | 32–36 |
| Disabled | พื้น border ตัว text-2 | — |
มุม 6 px · font 14/600 (มือถือ 16–18/600–700) · ไอคอน 16 px คู่คำ gap 8

### Form
- Label 14/600 อยู่บนช่อง · ช่องสูง 36 (มือถือ 56 สำหรับรหัส/เบอร์) ขอบ border-control มุม 6
- Help text 13 text-2 ใต้ช่อง
- Error: ขอบ 2px #B42318 + ข้อความ 13/600 แดงพร้อมไอคอน alert + `aria-invalid` + `aria-describedby`
- ฟอร์มที่มีหลาย error: Alert แดงด้านบนพร้อมลิงก์ไปช่องที่ผิด
- ตัวเลือกแบบการ์ด (radio card): ที่เลือก = พื้น accent-subtle ขอบ 2px accent
- **คำตอบที่เลือก (เช่น ไม่สะอาด / พบปัญหา) ใช้สีน้ำเงิน ไม่ใช่แดง**

### Status chip
- สูง 28 px มุม 6 px padding 0 10 · font 14/600 · ไอคอน 16 + คำ gap 6 · พื้น/ขอบ/ตัวหนังสือตามตารางสถานะ
- มือถือ "ทำอันนี้ก่อน" ใช้ chip ทึบ (พื้นสีสถานะ ตัวขาว) สูง 32 px

### Badge (ป้ายแยก)
- สูง 24 px มุม 4 px พื้นขาว ขอบสีอ่อน ตัวหนังสือสีเข้ม font 13/600 + ไอคอน
- สถานะ = พื้นสีอ่อน 28 px · ป้ายแยก = พื้นขาว 24 px → แยกกันได้แม้อยู่ติดกัน

### Alert
- padding 12/16 มุม 6 · ไอคอน 20 + หัวข้อตัวหนา + ข้อความ · info / success / warning / error ใช้สีสถานะ
- Error ต้องบอก **เกิดอะไร + ต้องทำอะไร** + ปุ่ม "ลองอีกครั้ง" ถ้าทำได้

### Table — กฎการจัดแนว (ตกลงจากการรีวิว)
- หัวตาราง 13/600 text-2 พื้น surface-2 · แถว 14 สูงอย่างน้อย 44–56 · เส้นแบ่งแถว border
- **ข้อความ** (ชื่อพื้นที่ ชื่อคน) → ชิดซ้าย
- **ตัวเลข/เวลา** → ชิดขวา + tabular-nums
- **ชิปสถานะในตาราง** → กว้างเท่ากันทุกแถว **124 px**, คำ+ไอคอนจัดกลางในชิป, **หัวคอลัมน์และเซลล์จัดกลาง** (คอลัมน์กว้าง 148 px)
- **คอลัมน์ปุ่ม** → ชิดขวา, ใช้ grid ความกว้างคงที่ให้ปุ่มอยู่ตำแหน่งเดิมทุกแถว (ปุ่มที่ไม่มีในแถวนั้นให้เว้นช่องไว้) ปุ่มสลับสถานะ (เปิด/ปิดใช้) กว้างคงที่ข้อความจัดกลาง
  - ตัวอย่าง: บัญชีผู้ใช้ `64px 84px 120px` (แก้ · รีเซ็ต · เปิด/ปิดใช้งาน) · ตึก `88px 104px` (แก้ชื่อ · เปิด/ปิดใช้)
- **เวลาที่แอดมินแก้** → ป้ายเล็ก `[✎ แก้]` (pencil 12px + "แก้", สูง 20) วาง **หน้าเวลาในบรรทัดเดียวกัน** ติดได้ทุกช่องเวลา (เข้างาน/ออกพัก/กลับจากพัก/เลิกงาน) ช่องเวลากว้าง 112 px · มี `title="แก้โดยแอดมิน"` · คำอธิบายใต้ตาราง "[แก้] = แก้โดยแอดมิน ดูเหตุผลในประวัติการแก้ไข"
- คอลัมน์ชื่อแม่บ้าน: แสดงชื่อเต็ม ป้าย "ทำแทน" ต่อท้าย (wrap ได้) — คงแบบเดิมตามที่รีวิว
- ป้าย/ชิปในตารางต้อง `white-space: nowrap` และใช้ `min-height` แทน `height` ตายตัว เพื่อไม่ให้ตัวหนังสือล้นกล่อง
- ตารางกว้างอยู่ในกล่อง `overflow-x: auto` · ด้านล่างมี "แสดง x–y จาก n" + ปุ่มก่อนหน้า/ถัดไป

### ตัวเลือกตึก (ตัวกรอง)
- ใช้ **dropdown (`<select>`)** กว้าง 340 px ไม่ใช้ปุ่มเรียงแถว เพราะรหัส/ชื่อตึกจริงยาวและจำนวนตึกเพิ่มได้
- ตัวเลือกแสดง "รหัส ชื่อเต็ม · มีปัญหา n จุด" เช่น `PRD-01 อาคารผลิต 1 · มีปัญหา 2 จุด` · ตัวแรก `ทุกตึก (6) · มีปัญหา 8 จุด`
- ในฟอร์มเลือกหลายตึก (ส่งออก Excel): แถว "ทุกตึก" แยกด้านบนพื้น surface-2 + "เลือกแล้ว x จาก n ตึก" · รายการตึกเป็น grid คอลัมน์เท่ากัน รหัสกว้างคงที่ 64 px (mono) ชื่อยาวตัดด้วย … + `title`

### Segmented / Tabs
- Segmented (เลือกกะ วัน ขนาดป้าย): กรอบ border-control ตัวที่เลือกพื้น accent ตัวขาว (คอม) · บนมือถือที่มีปุ่มหลักอยู่แล้ว ใช้ตัวที่เลือก = พื้น accent-subtle ตัว accent + เส้นล่าง 3px
- Tabs: สูง 48–52 เส้นล่าง 2px accent ที่แท็บที่เลือก + ตัวนับ

### Modal / Drawer
- Modal กว้างสุด 480 สำหรับยืนยัน/ฟอร์มสั้น · Drawer ขวากว้าง 480 สำหรับแก้ไขโดยไม่ทิ้งหน้าเดิม
- โครง: หัว (ชื่อ + ปุ่ม "ปิด" มีคำ) · เนื้อหา padding 20/24 · ท้าย (ยกเลิก + ปุ่มหลัก ชิดขวา)
- backdrop `rgb(16 24 40 / .45)` · เงา shadow-overlay · Esc ปิดได้ · focus trap · ยืนยันการทำลายใช้ `role="alertdialog"`

## 6. สถานะของหน้า (ทุกหน้าต้องมี)
- **กำลังโหลด**: spinner 16–20 px + ข้อความ "กำลังโหลด…" + skeleton (พื้น skeleton) โครงเดียวกับเนื้อหาจริง · `aria-busy`
- **ผิดพลาด**: Alert แดง บอกสาเหตุ + สิ่งที่ต้องทำ + ปุ่มลองอีกครั้ง
- **ว่าง**: ไอคอน 32 px สีเทา + หัวข้อ + คำอธิบายว่าจะมีข้อมูลเมื่อไร (+ ปุ่ม "ล้างตัวกรอง" ถ้าว่างเพราะตัวกรอง)
- **ปิดใช้**: กล่องเทาพร้อมไอคอน lock + ข้อความบอกผลและวิธีเปิดใหม่

## 8. Accessibility checklist
- ใช้ `<button>`, `<a href>`, `<input>` + `<label>` จริง ห้าม onClick บน div
- ทุกปุ่มกดได้ด้วยคีย์บอร์ด + focus ring 3px accent
- ตัวเลือกแบบ toggle ใช้ `aria-pressed`, แท็บใช้ `role="tab"` + `aria-selected`, เมนูปัจจุบัน `aria-current="page"`
- ไอคอนตกแต่ง `aria-hidden="true"`
- ฟอร์ม error ใช้ `aria-invalid` + `aria-describedby`
- ผลการส่ง/การบันทึกใช้ `role="status"`, error ใช้ `role="alert"`
