ผลของ Login ไม่สำเร็จ
401 = ชื่อ / secret ไม่ถูกต้อง หรือบัญชีปิดใช้งาน · 429 = Login Lock
ไม่มี session ใหม่ใน refresh_tokens · ตัวนับ Login Lock อยู่ในหน่วยความจำ server · เหตุการณ์ความปลอดภัยเขียน Server Log


จำ 3 จุดนี้ให้ได้
  1. สร้างบัญชี: hash เบอร์โทรหรือรหัสผ่าน → users.secret_hash
  2. Login: อ่าน User เดิม → Verify → สุ่ม refresh token → บันทึกเฉพาะ hash ใน refresh_tokens
  3. ฝั่ง Browser: refresh token ใน HttpOnly cookie / access JWT ใน Redux memory
ผลข้างเคียง: refresh เพิ่มแถวและหมุน token ทุกครั้ง จึงต้องดูแล retention; ระบบพึ่งฐานข้อมูลและ Login Lock แบบหน่วยความจำเหมาะกับ server เดียว เบอร์โทรที่คนอื่นรู้ยังใช้สวมบัญชีได้ตามความเสี่ยงที่ยอมรับใน facility-0054
