Prototype Ticket: scan-flow (#9)

เปรียบเทียบ Flow การสแกนบนมือถือ & จำนวนแตะ

คลิกสลับแท็บเพื่อทดลองสัมผัสประสบการณ์จริงของแต่ละ Flow และดูผลกระทบด้านความง่ายในการติดตั้งบน Mac / มือถือ

Flow 1: กล้องมือถือเปิดเว็บตรงๆ (Native Camera) แนะนำ
• แตะรวม: เพียง 2 ครั้ง (แตะเปิดลิงก์ + แตะยืนยัน)
• รันบน HTTP ธรรมดาได้ 100% ไม่ต้องลง Certificate บนมือถือส่วนตัวแม่บ้าน
Flow 2: เปิดเว็บก่อนแล้วเปิดกล้องในเว็บ (In-Web Camera)
• แตะรวม: 4 ขั้นตอน (เปิดเว็บ > กดปุ่มเปิดกล้อง > สแกน > ยืนยัน)
• ต้องติดตั้ง HTTPS (mkcert) บน Mac และนำ Root CA ไปติดตั้งบนมือถือแม่บ้านทุกเครื่อง
Flow 1: Native Phone Camera (สแกนผ่านแอปกล้องมือถือ)
👆 รวมเพียง 2 แตะ (แตะเปิดเว็บ + แตะบันทึก)
